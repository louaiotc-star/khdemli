# KHDEMLI — الموقع والخادم

## التشغيل المحلي

يتطلب Node.js 22.13 أو أحدث. شغّل الخادم من مجلد المشروع:

```powershell
npm.cmd start
```

ثم افتح `http://127.0.0.1:3000`. يعرض الخادم `index.html` ويوفّر واجهة API لحسابات المستخدمين والخدمات والمحادثات والتقييمات.

## غرفة الإدارة

في PowerShell، عيّن كلمة مرور عشوائية قوية قبل تشغيل الخادم. احتفظ بها بأمان؛ لا تُحفظ في ملفات المشروع:

```powershell
$adminPassword = node -e "process.stdout.write(require('node:crypto').randomBytes(32).toString('hex'))"
$env:ADMIN_PASSWORD = $adminPassword
$adminPassword
npm.cmd start
```

يعرض الأمر كلمة المرور في الطرفية لتتمكن من استخدامها عند تسجيل الدخول؛ احتفظ بها بأمان ولا تشاركها. افتح `http://127.0.0.1:3000/#/aa`. يلزم أن تكون بين 16 و128 حرفاً. تُحفظ جلسة المشرف في ملف ارتباط HttpOnly مستقل، وتُسجل عمليات فتح المحادثات وحذف الخدمات في قاعدة البيانات. لا تُعرض الرسائل للمشرف إلا بعد فتح محادثة محددة من الغرفة.

تُخزّن البيانات في `data/khdemli.sqlite`، ويُنشأ الملف تلقائياً عند أول تشغيل. تُشتق كلمات المرور باستخدام scrypt مع ملح عشوائي؛ لا تُحفظ كلمات المرور كنص صريح. ملفات الجلسات تخزن بصمة رمز عشوائي، ويُرسل الرمز إلى المتصفح في ملف ارتباط HttpOnly.

في وضع الإنتاج، يستمع الخادم على `0.0.0.0` ويستخدم المنفذ الذي توفره الاستضافة عبر `PORT`. محلياً يستمع افتراضياً على `127.0.0.1`. أوقف الخادم قبل نسخ قاعدة SQLite احتياطياً.

## النشر على استضافة تدعم Node.js

رفع `index.html` وحده إلى مجلد الملفات الثابتة لا يكفي؛ يجب نشر المشروع كاملاً كتطبيق Node.js وتشغيل أمر البدء `npm start` أو `node server.js`. اختر Node.js 22.13 أو أحدث، ووجّه نطاق التطبيق إلى الخادم نفسه، لأن الواجهة تستدعي `/api` على النطاق ذاته. اضبط `NODE_ENV=production` و`ADMIN_PASSWORD` في إعدادات الأسرار لدى مزوّد الاستضافة، ولا تضع كلمة مرور المشرف في ملفات المشروع.

تأكد أن لدى الاستضافة قرصاً دائماً للبيانات، وعيّن `DATA_DIR` إلى مجلد ذلك القرص. بعض الخطط المجانية تمسح الملفات المحلية عند إعادة التشغيل؛ عندها ستفقد الحسابات والخدمات والرسائل. إذا كانت الاستضافة لا تشغّل عمليات Node.js طويلة الأمد أو لا توفر تخزيناً دائماً، فلن تعمل معها قاعدة SQLite المحلية؛ استخدم استضافة Node مناسبة أو قاعدة بيانات مُدارة مدعومة.

لا يتضمن هذا الخادم استعادة الحسابات القديمة. حسابات الموقع تُنشأ على قاعدة البيانات الجديدة.
